Important correction:
Use a 30-day trial, not a 14-day trial.

Goal:
When SuperAdmin converts a prospect into an organization, the system should fully prepare that organization for first use.

Current issue:
Conversion creates an org and admin user, but it does not fully activate the client.

Expected behavior:
When a prospect is converted to an organization:

1. Create organization record.
2. Create admin user.
3. Create org_subscriptions record.
4. Set subscription status to trial.
5. Set trialStartedAt = now.
6. Set trialEndsAt = now + 30 days.
7. Use the prospect suggestedTier to populate the plan/tier if available.
8. Create org_setup_progress record with all setup steps set to false:
   - hasAddedProperty
   - hasInvitedStaff
   - hasConnectedStripe
   - hasImportedClients
   - hasConfiguredService
9. Update onboarding_prospect:
   - stage = converted
   - convertedAt = now
10. Send invite/welcome email to the new org admin.
11. Show SuperAdmin a conversion success summary:
   - org name
   - admin email
   - trial end date
   - link to org if available

Add setup progress endpoints:
- GET /api/orgs/:orgId/setup-progress
- PATCH /api/orgs/:orgId/setup-progress

These should be authenticated and same-org or super-admin scoped.

- propertyId
- serviceId
- clientContactId optional

- billingFrequencyOverride optional
